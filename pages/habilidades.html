Habilidades

A lo largo de mi formación académica y de los cursos que estoy realizando fui adquiriendo conocimientos en distintos lenguajes de programación, herramientas y tecnologías. Actualmente continúo ampliando estas habilidades y aprendiendo nuevas herramientas relacionadas con el desarrollo web.

Lenguajes y tecnologías

  • Java: conocimientos adquiridos durante mi formación universitaria.
  • Python: conocimientos de programación adquiridos mediante trabajos y ejercicios académicos.
  • HTML5: creación y estructuración de sitios web utilizando etiquetas semánticas, enlaces, imágenes, listas y navegación entre páginas.

Herramientas

  • Visual Studio Code: editor que utilizo actualmente para desarrollar mis proyectos.
  • Microsoft Excel: manejo de hojas de cálculo, organización de información y utilización de sus principales herramientas.
  • Microsoft Word: creación, edición y formato de documentos.

Conocimientos de desarrollo web

  • Estructura básica de una página web.
  • HTML semántico.
  • Creación de sitios con múltiples páginas.
  • Navegación mediante enlaces.
  • Incorporación de imágenes y contenido multimedia.

Actualmente aprendiendo

  • CSS: para aplicar estilos y diseño visual a páginas web.
  • Git: para el control de versiones de proyectos.
  • GitHub: para almacenar, administrar y compartir proyectos.
