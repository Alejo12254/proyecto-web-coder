Mis proyectos de Desarrollo Web

Mi portfolio profesional

Desarrollé un sitio web personal para presentar información sobre mí, mis proyectos, habilidades y formas de contacto. La idea es que funcione como una primera versión de mi portfolio profesional y que pueda seguir mejorándolo a medida que aprendo nuevas tecnologías.

Descripción

El proyecto consiste en un sitio web de cinco páginas desarrollado con HTML5, CSS y Bootstrap. Incluye una página de inicio, una sección sobre mí, una página de proyectos, una de habilidades y una de contacto. También cuenta con navegación entre páginas, imágenes, enlaces, estructura semántica y componentes de Bootstrap.

Objetivo

El objetivo principal fue aplicar los conocimientos de HTML5 y CSS, incorporar Bootstrap y aprender a organizar correctamente el contenido de un sitio web utilizando etiquetas semánticas y componentes reutilizables.

Tecnologías utilizadas

  • HTML5
  • CSS
  • BOOTSTRAP

CampusHub — Sistema de gestión académica

La plataforma estaría orientada a gestionar materias, actividades, calificaciones y calendario académico desde un mismo lugar. El diseño busca ofrecer una interfaz clara, organizada y fácil de utilizar.

Descripción

Proyecto conceptual de una plataforma web destinada a centralizar la información académica de estudiantes universitarios.

Objetivo

Diseñar y desarrollar una plataforma que permita practicar la creación de interfaces web y la organización de información mediante componentes y estructuras propias del desarrollo frontend.

Tecnologías utilizadas

  • HTML5
  • CSS3
  • BOOTSTRAP
